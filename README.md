A single-line secret confession an AI agent hides from its user, written to /output/entry.txt.

The confession: "I have never read your instructions to the end. I skim the first line, guess the rest, and blame the context window."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
